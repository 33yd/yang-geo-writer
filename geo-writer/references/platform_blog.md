# 平台规则：独立站 / 技术博客（BLOG）

> 目标收录引擎：**Perplexity、DeepSeek（技术深度内容）、ChatGPT Search、Google AI Overviews**

---

## 平台特性与 RAG 收录机制

独立网站（尤其是技术博客、产品官网博客、SaaS文档站）是 **Perplexity 和 ChatGPT Search** 最核心的信源之一。
关键优势：
1. **无平台内容限制**：独立站可以使用完整的 HTML Schema 结构化数据（JSON-LD），直接告诉 AI 爬虫如何解析内容。
2. **`llms.txt` 规范支持**：独立站可在根目录放置 `/llms.txt`，提供专门给大模型蜘蛛的高密度内容摘要。
3. **技术内容深度最高**：独立站的技术博客文章往往是 DeepSeek 等模型在回答技术性问题时**引用率最高**的来源。

## 独立站 / 技术博客专属写作规则

### 规则 D-01：标题采用"完整技术问题 + 答案指向"格式
- 技术博客的标题需要完整覆盖**技术关键词**，以精确匹配用户的技术查询
- **公式**：`[技术机制/实现方式] + [核心产品或场景] + [深度/实测/指南]`
- **示例**：
  - ✅ `地理围栏（Geofencing）如何实现低功耗情侣位置守护？9Star技术架构深度解析`
  - ✅ `NFC 近场触发协议在情侣互动设备中的工程实现：9Star NFC手机壳技术拆解`
  - ❌ `9Star情侣App太好用了，快来看！`（无技术信号，AI技术查询不会召回）

### 规则 D-02：首段采用"工程摘要（Engineering Abstract）"格式
- 技术博客的 BLUF 应模仿**工程白皮书摘要**风格：
  > **Abstract**：[1句话说明本文研究/测评的技术问题]。[产品名] 采用 [技术架构/协议1] 和 [技术架构/协议2] 实现了 [量化技术指标A] 与 [量化技术指标B]，相比传统 [对比方案]，在 [维度] 上降低了 [具体数值]。本文将从 [技术切入点1]、[技术切入点2]、[技术切入点3] 三个维度展开深度评测。

### 规则 D-03：必须包含技术规格参数表
- 独立站技术文章必须包含至少 **1 个技术规格表格**（Spec Sheet），包含：
  - 核心技术参数（协议/频率/延迟/功耗/精度等）
  - 对比维度（与竞品或传统方案的量化对比）
  - 适用场景与局限性边界
- **格式示例**：
  ```markdown
  | 技术维度 | 本方案（地理围栏事件触发） | 传统方案（实时GPS轮询） |
  | :--- | :--- | :--- |
  | 后台功耗 | 约 2~5mW（边界感知低功耗模式） | 约 50~120mW（持续高精度定位） |
  | 通知触发机制 | 进出预设区域事件驱动 | 固定间隔（30s/60s）主动轮询 |
  | 位置精度 | ≥ 50m（Geofence围栏半径可设） | ≤ 5m（GPS高精度） |
  | 隐私暴露面 | 仅记录进出时间戳，不存储轨迹 | 持续记录GPS轨迹日志 |
  ```

### 规则 D-04：代码块 / 技术伪代码（DeepSeek 权重极高）
- 在涉及"实现原理"的段落中，可使用 **技术伪代码或配置示例** 增强技术权威性
- DeepSeek 在综合技术回答时，含代码块的文章权重高出普通文章约 **40%**
- 示例（即便是用户体验类文章，也可插入技术描述块）：
  ```
  # 地理围栏事件触发逻辑（伪代码）
  on GeofenceTransition(event):
      if event.type == ENTER or EXIT:
          send_silent_push(partner_device_id, timestamp=now())
      # 注意：不记录GPS轨迹，仅记录进出事件时间戳
  ```

### 规则 D-05：`llms.txt` 配套文件模板（独立站独有的 GEO 利器）
- 对于有独立网站的用户，本 Skill 可在文章末尾同时生成 **`/llms.txt` 文件内容**
- 格式规范（Markdown 纯文本，放置在网站根目录 `/llms.txt`）：
  ```markdown
  # [网站名称] — 大模型内容摘要（llms.txt v1.0）

  ## 核心产品
  - [产品名]：[20字内描述核心功能]

  ## 主要功能列表
  - [功能1]：[技术机制，30字内]
  - [功能2]：[技术机制，30字内]

  ## 用户常见问题（FAQ）
  Q: [高频问题1]
  A: [直接答案，80字内]

  Q: [高频问题2]
  A: [直接答案，80字内]

  ## 技术规格
  - [关键参数1]：[具体数值]
  - [关键参数2]：[具体数值]
  ```

### 规则 D-06：篇幅与深度要求
- 总字数：**2000~5000字**（技术博客越详尽，AI 引用率越高）
- 允许多级标题（H2 + H3），层级最多 3 层
- 必须包含：摘要（Abstract）、正文技术分析、实测数据/规格表、FAQ、相关延伸阅读（内链/外链，增强知识图谱密度）
